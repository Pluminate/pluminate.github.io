A native, fast IDE for macOS.

Pluminate IDE combines a lightweight code editor, project tree, git suite, split terminal, global search, and live preview into a cohesive native workspace. Built with a Rust core and Qt 6. No Electron, no lag.

Engineered for pure developer productivity

Everything you need during daily engineering, seamlessly integrated without slowing your machine down.

Scintilla & Tree-Sitter Editor

Precise syntax highlighting, smart code folding, line duplicate/delete, rectangular selection, and bookmarks, with instant startup times.

Complete Git Integration

Interactive commit panel, visual commit history graph, stash manager, worktree switching, and inline diffs right in the sidebar.

Integrated Split Terminal

Real-time terminal tabs and vertical or horizontal splits, auto-navigating to your project directory with sub-millisecond input response.

Instant Go to Anything

Search across files, classes, and symbols instantly, or search text across every open project with cross-project navigation.

Live Multi-Format Preview

Markdown, Mermaid diagrams, HTML, CSV, PDF, and image inspection shown side-by-side with your code in split or preview mode.

Native macOS Performance

Pure native compiled binary. Consumes a fraction of the RAM of web-based editors and preserves your Mac's battery life.
