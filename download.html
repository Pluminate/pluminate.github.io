Install

macOS

  1. Open the downloaded .dmg.
  2. Drag Pluminate onto the Applications folder.
  3. Open Pluminate from Applications or Launchpad, then choose File → Open Folder.

Debian and Ubuntu

Install with apt, which also installs the Qt libraries and ripgrep it needs:

sudo apt install ./pluminate_amd64.deb

Then start it from your application menu, or run pluminate in a terminal. To remove it, run sudo apt remove pluminate.

Ubuntu 24.04 LTS and older: not supported yet, because those releases ship an older version of Qt than Pluminate needs.
