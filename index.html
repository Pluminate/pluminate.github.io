The depth of an IDE. The speed of an editor.

Pluminate is a native IDE for macOS, Windows and Linux. It opens fast, searches your whole project instantly and understands your code, so you stay in flow as AI changes the way software gets written.

Download for free Take the tour

Apple silicon and Intel Macs, Debian and Ubuntu. Also coming to the Mac App Store as Pluminate Lite.

Most tools make you pick.

Heavyweight IDEs give you depth but can be slow to start. Lightweight editors give you speed and leave you to assemble the rest. Pluminate is built so you do not have to choose.

Depth that understands your project

The things you reach for every hour are built in and work together.

  • Search everywhereFind classes, files and symbols from a single box, across every project you have open.
  • Code navigationJump to definitions in Kotlin and Python through language servers. More languages are on the way.
  • Git in the same windowCommit, branches, worktrees, stashes, history and conflict resolution, with no second app.
  • A real terminalTabs and split panes that start in your project folder.
  • Previews for what you writeMarkdown with Mermaid diagrams, CSV tables, images and PDFs open right in the editor.

Speed from the ground up

The editor core is written in Rust and the interface in Qt. There is no Electron shell between you and your keystrokes.

  • Search that keeps upProject search is built on ripgrep, so large repositories stay responsive.
  • Highlighting as you typeTree-sitter parsing colours your code instantly, for 45 languages, with no plugins to install.
  • Native on every platformA true Mac, Windows and Linux app, not a web page in a window.
  • Every shortcut is yoursA familiar IDE keymap out of the box, and any action can be rebound in Settings.
  • Private by defaultYour code stays on your machine unless you choose to send it somewhere.

Where Pluminate is headed

Three things come first: more programming languages, a faster IDE, and AI support that respects your code.

Available now

  • Highlighting for 45 languagesBuilt in, with no plugins.
  • Search, Git, terminal and previewsEverything in the tour above.
  • Navigation for Kotlin and PythonGo to definition through language servers.
  • AI commit messagesOptional. You add your own Gemini API key, and nothing is sent until you ask.

In focus

  • More languages, deeper supportNavigation and code intelligence for more of the languages you write.
  • A faster IDEStartup, indexing and responsiveness on very large projects, checked on every release.
  • AI supportHelp in the editor that understands your whole project and works with the model you choose.

On the plan

  • DebuggingBreakpoints, stepping and inspecting variables. Not available yet, and not forgotten.

Pluminate and AI

More and more of the code in your editor will be written with AI help. We want Pluminate to be the place where you can read, search, review and change that code quickly.

Ideas we are exploring include inline suggestions, asking questions about your project, and reviewing AI-written changes as a diff. You will choose the model, and your code goes only where you send it.

This is direction, not a promise. Priorities and timing can change as we learn from the people using Pluminate.
