Open-source notices

Last updated: 11 November 2026

Pluminate is built with the help of open-source software. This page lists the main components and the licenses they are used under. It is not an exhaustive list of every transitive dependency.

Qt

Pluminate's interface is built with the Qt toolkit (including Qt WebEngine in Pluminate Free), used under the GNU Lesser General Public License version 3 (LGPLv3). Qt is linked dynamically and shipped as separate libraries inside the application. The source code of Qt is available from download.qt.io, and the license text is at gnu.org/licenses/lgpl-3.0.html. Qt is a trademark of The Qt Company Ltd. Qt WebEngine is based on Chromium and its own open-source components; see Qt WebEngine licensing.

ripgrep

Project search uses ripgrep by Andrew Gallant and contributors, dual-licensed under the MIT License and the Unlicense.

Tree-sitter and language grammars

Syntax highlighting uses Tree-sitter and its community grammars, which are distributed under permissive licenses (mostly the MIT License). Each grammar is the work of its authors.

Rust libraries

The Pluminate core is written in Rust and uses open-source crates from crates.io, under licenses such as MIT and Apache-2.0.

Fonts on this website

  • Bricolage Grotesque, SIL Open Font License 1.1.
  • Geist and Geist Mono, SIL Open Font License 1.1.
